# Sudokura v1.1.0

Sudokura v1.1.0 refreshes the original game with a cleaner interface, better support for compact windows, new languages, and desktop packages for Linux, Windows, and macOS.

<p align="center"><img src="https://raw.githubusercontent.com/santirodriguez/Sudokura/6f15ddc81e3600489e61fcea3b090bb00ca970de/docs/images/sudokura-v1.1.0.png" alt="Sudokura v1.1.0 game interface" width="900"></p>

Feel free to download, play, and report any issue.

## ✅ Supported platforms

- **Linux x86_64:** tested manually.
- **Windows x86_64:** tested manually.
- **macOS Intel and Apple Silicon:** available as untested unsigned builds; feedback from Mac users is appreciated.

## What’s new

- A redesigned responsive interface that stays compact and readable across desktop, ultrawide, and portrait window sizes.
- A new 3×3 number palette, tidier controls, improved typography, and clearer visual states.
- Complete English, Argentine Spanish, and Catalan translations with an in-game language selector.
- New Sudokura logos, application icons, and in-game branding.
- More reliable puzzle generation, gameplay checks, responsive-layout tests, and text-fit validation.
- Portable packages for Linux and Windows, plus macOS app bundles for Intel and Apple Silicon.
