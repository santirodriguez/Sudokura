# Audio provenance

The four OGG files in this directory come from **Cozy Puzzle Jingle & Result** by **MintoDog**, published on OpenGameArt under **CC0**.

Source: https://opengameart.org/content/cozy-puzzle-jingle-result

Sudokura keeps the audio offline and ships the original OGG payloads without recompression. The files were renamed only to make their runtime purpose explicit:

- `music-main.ogg` ← `Clear (Loop)`
- `jingle-win.ogg` ← `Clear (Jingle)`
- `music-fail.ogg` ← `Failure (Loop)`
- `jingle-fail.ogg` ← `Failure (Jingle)`

CC0 does not require attribution, but the project preserves the author, source, and license here and in the public About/README documentation so the provenance is not lost.
